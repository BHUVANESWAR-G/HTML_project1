# 🚀 E-Learning & Training Website

A simple and beginner-friendly **static website project** built using HTML. This project showcases a tech learning platform with course details and a registration form.

---

## 📌 Project Overview

This website is designed to introduce users to **Error Makes Clever Academy**, a platform focused on:

* 💻 Tech Training
* 📰 Tech News
* 🎓 Freshers Guidance

It includes:

* A homepage with an embedded YouTube video
* A course overview section
* A registration form for learners

---

## 🛠️ Technologies Used

* HTML5
* Basic Form Elements
* Embedded YouTube Video (iframe)

---

## 📂 Project Structure

```
📁 Project Folder
│── index.html        # Home page with video and course info
│── register.html     # Registration form page
│── emc.png           # Website favicon/logo
```

---

## 🖥️ Features

### 🏠 Home Page (`index.html`)

* Displays academy introduction
* Embedded YouTube video
* Explanation of Full Stack Development
* Technologies table (Frontend, Backend, Database)

### 📝 Registration Page (`register.html`)

* User input form including:

  * Name, Age, Gender
  * Email
  * Course selection
  * Resume upload
* Navigation links to Home & Social Media

---

## 🎯 Learning Objectives

This project helps beginners understand:

* HTML page structure
* Forms and input elements
* Tables and lists
* Embedding external content (YouTube iframe)
* Basic navigation between pages

---

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open `index.html` in your browser
3. Navigate using links to explore the site
